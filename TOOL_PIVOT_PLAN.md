## 🛠️ Phase 1 详细设计

### 工具 1：ChatSaver（对话保存器）

#### 痛点
- Character.AI、JanitorAI 等平台**没有官方导出功能**
- 用户想保存重要对话（写作素材、情感记录）
- 对话可能会被删除或账号被封

#### 解决方案
用户粘贴对话文本 → 格式化为可保存的页面 → 生成永久链接

#### 功能规格

```
┌─────────────────────────────────────────────────────────┐
│  ChatSaver - AI 对话保存器                                │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  [粘贴对话内容]                                          │
│  ┌─────────────────────────────────────────────────────┐│
│  │ You: 你好呀                                          ││
│  │ Bot: 你好！今天过得怎么样？                            ││
│  │ You: 还不错，刚完成一个项目                            ││
│  │ Bot: 太棒了！是什么类型的项目？                        ││
│  └─────────────────────────────────────────────────────┘│
│                                                         │
│  角色风格（可选）:                                        │
│  [Yandere ▼] [Romance ▼] [Fantasy ▼] [Custom ▼]        │
│                                                         │
│  标题（可选）: [给你的对话起个名字...]                    │
│                                                         │
│  [💾 保存对话]                                           │
│                                                         │
└─────────────────────────────────────────────────────────┘

生成结果：
┌─────────────────────────────────────────────────────────┐
│  ✅ 对话已保存！                                         │
│                                                         │
```

### 工具 3：ChatAnalyzer（对话分析器）

#### 痛点
- 用户觉得 AI 对话"无聊"、"重复"
- 不知道怎么改进对话技巧
- 不知道自己的对话风格

#### 解决方案
粘贴对话 → AI 分析语气、节奏、情感 → 提供改进建议

#### 分析维度

| 维度 | 分析内容 | 改进建议示例 |
|------|---------|-------------|
| **语气一致性** | 角色语气是否稳定 | "角色后期语气变软，建议保持一致" |
| **对话节奏** | 回复长度分布 | "你的回复偏短，尝试更详细的描述" |
| **情感曲线** | 对话情感走向 | "建议在第3轮加入更多情感互动" |
| **创意指数** | 描述性内容比例 | "加入更多场景描写可以提升沉浸感" |
| **互动质量** | 问题 vs 陈述比例 | "多问开放式问题可以推动剧情" |
