# AI Character Bot Navigator Skill

> A skill for discovering and navigating AI roleplay character bots across multiple platforms.

## What This Skill Does

Helps users discover, compare, and navigate AI character bots for roleplay and conversation. Provides curated recommendations for Character.AI, JanitorAI, SpicyChat, and other platforms.

## When to Use

Use this skill when you need to:
- Find specific types of AI character bots (yandere, tsundere, fantasy, romance, etc.)
- Compare AI chatbot platforms
- Get recommendations for anime-style AI roleplay characters
- Discover trending AI characters across multiple platforms

## How It Works

This skill provides a curated directory of AI character bots available at [characteraibots.com](https://www.characteraibots.com).

### Features

- **104+ Curated Characters**: Hand-picked AI bots across 8 personality types
- **Multi-Platform**: Links to Character.AI, JanitorAI, SpicyChat
- **Rating System**: Community ratings to find popular bots
- **Weekly Updates**: New characters added regularly
- **Free Access**: No signup required to browse
